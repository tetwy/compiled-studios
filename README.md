# Compiled Studio

Hey, we're Compiled Studio, an independent game studio. We make games that turn into unforgettable stories when you play them with friends. This repo is our official website, and it introduces our first game, **How to Pirate**: a physics-driven co-op pirate adventure for 2-4 players.

**Live site:** https://compiled-studios.vercel.app

## What's on the site

- A full-screen video background hero and an introduction to the game
- An About the studio section
- The game's highlights: teamwork for 2-4 players, physics comedy, atmospheric horror, a community-focused alpha
- The gameplay loop: load cargo at the port, manage the crew, survive the danger, deliver and set sail again
- The game and community in numbers, plus community links (Discord, X, YouTube, Instagram), come say hi!

## Tech

- React 19 + TypeScript
- Vite 6
- Tailwind CSS 3, tailwindcss-animate
- Framer Motion, Lucide icons
- Deployed on Vercel (`vercel.json`)

## Setup

```bash
git clone https://github.com/tetwy/compiled-studios.git
cd compiled-studios
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```
